# 📁 File Information Extractor Project
A simple Python script to list files and their sizes in any directory (including subfolders).

## 🔍 What This Script Does
This project creates a script that scans your computer's files and returns information like:

File name
File size (in bytes)
Full file path
Perfect for auditing files, learning Python, or understanding how to interact with your operating system.

🧠 How It Works
1. Foundational Version
Lists files in the current working directory.
Uses Python’s built-in os module to get file names and sizes.

2. Advanced Version
Recursively scans subdirectories using os.walk().
Accepts an optional path parameter (defaults to the current directory).

## ✅ Features
No external libraries required (uses Python’s standard tools).
Recursive scanning for nested folders.

Flexible function : Works for any directory path.
